### Core Focus & Engineering Philosophy
Specializing in secure distributed data systems, high-throughput machine learning infrastructure, and local-first execution environments. I prioritize explicit type safety, clean modularity, and minimal external dependencies across Go, Rust, Python, and TypeScript stacks.

### Key Open-Source Projects

* **[AIR-Kit-AI/AIR-Kit](https://github.com/AIR-Kit-AI/AIR-Kit)** — Open-source local-first security platform and autonomous blue-team infrastructure for telemetry analysis and incident response automation.
* **[ForestMars/Polyglot](https://github.com/ForestMars/Polyglot)** — Local RAG engine integrated with PostgreSQL `pgvector` and multi-tier LLM sidecar orchestration.
* **Devo** — Platform engineering CLI tool in Go for rapidly spinning up self-contained local application development environments with Docker Compose, ClickHouse, and Grafana.
* **jev-router & cascade-router** — High-performance Rust routing engines implementing multi-tier LLM fallback, FastText classification, and local sidecar scoring.
* **FelonyBench** — Open-source evaluation suite tracking agentic model capabilities against statutory crime definitions.
